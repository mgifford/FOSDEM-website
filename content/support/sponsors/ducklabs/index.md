DuckLabs is the Amsterdam-based company behind DuckDB, an open-source
analytical database designed to make data analysis fast, portable and simple.
DuckLabs employs the key contributors to the DuckDB, DuckLake and Quack
projects.

DuckDB is designed to be extensible: the Community Extensions repository lets
anyone publish extensions that add new file formats, functions and
integrations.

Since September 2026, DuckLabs has operated as a subsidiary of Amazon Web
Services. The intellectual property and trademarks remain with the non-profit
DuckDB Foundation, which keeps the project open source under the MIT license.

DuckLabs supports the event financially.
